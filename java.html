What is Java?

Java is a programming language, just like C and Python. You may be wondering — where is Java actually useful?

Java is widely used to develop software applications. Coding is an important part of many fields because it helps us create and use different applications and online services.

For example, when we use an application like Meesho, we interact with different features, forms, questions, buttons, and other functionalities. All of these are made possible through programming.

Java can be used in developing different parts of applications, including backend systems and many other software applications. I will explain what frontend and backend mean in the upcoming topics.

But before going into all of that, let's start with the basics of Java.

Java and C

Many of us may learn C before Java, just like we do in college. Since I have also started with C, I will sometimes compare Java with C to make certain concepts easier to understand.

For example, in C, we use printf() to print something on the screen, whereas in Java, we commonly use System.out.println().

I will explain these differences and the reasons behind them in detail when we reach those concepts.

How did Java get its name?

Java was developed at Sun Microsystems, with James Gosling being one of the key people behind its development.

Java was originally called Oak. The name was later changed to Java.

One commonly shared story is that there was an oak tree near James Gosling's office, which inspired the original name. Later, because the name Oak was already associated with another trademark, the name was changed.

The new name, Java, was associated with coffee, which is why you may often see the coffee theme connected with Java.

Features of Java

Java has several features that make it a popular and widely used programming language.

1. Compiled and Interpreted

Java uses both compilation and interpretation. The Java source code (.java) is first compiled by the Java compiler into bytecode (.class). The JVM then executes this bytecode. Modern JVMs also use JIT (Just-In-Time) compilation to convert frequently executed bytecode into native machine code for better performance.

Java Source Code → Compiler → Bytecode → JVM → Machine Code

2. Platform Independent

Java is platform independent because Java programs are compiled into bytecode, which can run on different operating systems as long as a suitable JVM is available.

“Write Once, Run Anywhere.”

3. Object-Oriented

Java follows the Object-Oriented Programming (OOP) approach. Programs can be organized using classes and objects. Objects contain data and methods that operate on that data.

4. Robust

Java is considered robust because it provides features such as exception handling and garbage collection, which help make programs more reliable and manage memory effectively.

5. Secure

Java provides several security mechanisms such as bytecode verification, access controls, and class-loading security mechanisms to help run programs safely.

6. Dynamic

Java can load classes and resources during runtime, making it a dynamic programming language.

7. Distributed

Java supports the development of distributed applications that communicate across different systems and networks.

8. Simple and Familiar

Java has a simple and familiar syntax, with similarities to languages such as C and C++, making it easier to learn.

9. Portable

Java programs can be moved between different platforms without requiring major changes.

10. High Performance

Java provides good performance through bytecode execution and JIT (Just-In-Time) compilation.

11. Multithreaded

Java supports multithreading, allowing a program to perform multiple tasks concurrently.

12. Architecture Neutral

Java bytecode is not tied to a specific processor architecture, allowing Java programs to run on different systems through their JVM implementations.

How Java Code Works

Unlike languages such as C, Java does not directly convert source code into machine code.

When we write a Java program, the source code is saved with the .java extension. The Java compiler (javac) compiles the source code and converts it into bytecode. This bytecode is stored in a .class file.

JVM – Java Virtual Machine

The JVM (Java Virtual Machine) loads and executes the bytecode. It provides the environment required to run Java programs on different operating systems.

JIT – Just-In-Time Compiler

The JIT compiler is a part of the JVM. It converts frequently executed bytecode into machine code at runtime, which helps improve the performance of Java programs.

JRE – Java Runtime Environment

The JRE (Java Runtime Environment) provides the environment and libraries needed to run Java applications. It includes the JVM and the required Java class libraries.

How Do We Write a Program in Java?

Java is an Object-Oriented Programming (OOP) language. This means Java programs are mainly designed around classes and objects.

🔹 What is an Object?

An object is a real-world entity or thing that has properties and behavior.

For example, think about flowers:

  • Rose
  • Sunflower
  • Lotus

Here, Flower can be considered as a class, while Rose, Sunflower, and Lotus can be considered as objects or instances of that class.

🔹 What is a Class?

A class is a blueprint or template used to create objects. 


         Flower
        /   |   \
     Rose  Lotus  Sunflower

Here, Flower is the class, and individual flowers can be created as objects from that class.

A class can contain variables and methods that describe the properties and behavior of its objects.

Let's Write Our First Java Program

A simple Java program looks like this: 




class Sample {
public static void main(String[] args) {
System.out.println("Hello, World!");
}
}

🔹 Let's understand every part of this program.

1. class Sample




class Sample

class is a keyword in Java.

A keyword is a word that has a special meaning to the Java compiler. We cannot use Java keywords as normal variable or class names.

Examples of Java keywords are:

Here, Sample is the name of our class.

The complete class is written inside curly braces { }. 




class Sample {
// program goes here
}

2. public static void main(String[] args)

This is the main method of our Java program. 




public static void main(String[] args)

The Java Virtual Machine (JVM) looks for this main() method as the starting point when we run a normal Java application.

Let's understand each word.

public

public is an access modifier.

It means that the method can be accessed from outside the class. The main() method needs to be accessible to the JVM, so it is declared as public.

static

static means that the method belongs to the class itself, rather than requiring an object of the class to be created first.

Because main() is static, the JVM can call it without creating an object of Sample.

void

void specifies the return type of the method.

It means that this method does not return a value. 



void display() {
// no value is returned
}

main

main is the name of the method that serves as the entry point for a standard Java application.

String[] args

This represents an array of strings that can receive command-line arguments.

For a beginner, you can simply remember that String[] args allows values to be passed to the program when it is started from the command line.

🔹 3. System.out.println()

Now we come to the statement that actually displays something on the screen. 



System.out.println("Hello, World!");

Let's break it down:

System

System is a predefined class provided by Java.

out

out represents the standard output stream, which is normally connected to the console.

println()

println() is a method used to print a value on the screen and move to the next line.

For example:



System.out.println("Hello");
System.out.println("Java");

Output:



Hello
Java

Do We Need import java.io.*;?

You may have seen Java programs beginning with: 




import java.io.*;

But we do not need it for this simple program.

Our program uses System.out.println(), and the System class is available through java.lang, which Java automatically makes available.

So our simple program can directly start with: 




class Sample {
public static void main(String[] args) {
System.out.println("Hello, World!");
}
}

We use import when we want to use classes from packages that are not automatically available.

For example, when working with input/output classes such as BufferedReader, we may need an appropriate import.
